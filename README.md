## 1️⃣ 金蝶苍穹 ERP 数据同步管理平台（数据中台）｜独立设计开发 · 持续迭代

**定位**：把金蝶苍穹 7 条业务线单据自动同步到飞书多维表，替代人工导表，全链路无人值守。  
**技术栈**：Python · FastAPI · APScheduler · 飞书多维表 API · 金蝶 Open API · JSON 持久化 · MCP Server

**背景痛点**

- 采购 / 报关 / 财务数据在金蝶苍穹，业务方在飞书多维表协同，两套系统隔离形成数据孤岛
- 原先靠人工查单、搬数、做表：**单笔约 15 分钟**，慢、易漏、不可溯源

**核心功能明细**

- 接入 **7 条业务线**：采购订单 / 海运单 / 采购入库单 / 销售出库单 / 财务应付单 / 暂估应付单 / 采购付款单，覆盖采购全链路
- 封装金蝶 Open API：**OAuth2 Token 自动刷新**、分页遍历、字段映射
- 全量覆盖同步机制：清表 → 明细行展开 → 批量写入飞书，**单批次最大处理 271 条明细行**
- APScheduler 调度引擎：**interval / daily / multi_daily 三种模式**，失败自动重试、任务可启停
- 同步目标**前端可配**（App Token + Table ID），换表不改代码
- 字段三层映射校验（业务层 → 扁平化层 → 飞书字段定义）+ 首次同步自动建列
- 自研 **MCP Server** 输出结构化业务 Schema，AI 工具可直接按标准接口取数
- FastAPI 管理端（5001）+ 7 天成功率看板 + JSON 持久化 + 原生 HTML/CSS/JS 单文件前端（Dark Mode）

**业务价值**

- 月同步单据 **1 万+ 张** 自动入表；累计同步 **270 万+ 行**（飞书多维表）
- 7 天成功率 **98.2%**；单次同步峰值 **1.4 万+ 行** / 耗时约 290–466 秒，全链路零失败
- 人工导表（15 分钟/单）→ 一键触发 / 自动调度，**业务响应效率提升 90%+**
- 同步目标与业务线解耦、异常可追溯，业务查询 / 核对从每天多次人工操作降为 0

## 2️⃣ 出口报关单据自动追踪与对账系统｜独立开发 · 2026.08 – 2026.09

**定位**：自建金蝶 MCP 数据源，以「柜号」为主键自动聚合 5 类报关单据完成对账，一键生成追踪表并落地飞书多维表，替代人工 Excel 合并。  
**技术栈**：Python · openpyxl · 金蝶 Open API / 自建 MCP Server · 飞书多维表

**背景痛点**

- 出口报关需把分散在 5 类单据（海运提单、销售出库、采购入库、财务应付、采购发票）里的字段**手工合并成一张追踪表**
- 人工整理效率低、易错、**不可溯源**

**核心设计明细**

1. **柜号主键聚合**：5 类单据中仅海运单稳定带柜号 → 其余单据经业务关联回溯到柜号，实现"一柜到底"横向聚合
2. **应付单 → 柜号（双路径挂接）**：海运单号 + 采购订单号双路径挂接，解决单据间无直接关联键的问题
3. **发票 → 采购合同（精确匹配）**：发票主表无合同号字段，从发票"备注"**正则提取合同号 + 大小写不敏感精确匹配**，替代原人工录入发票号的模糊桥接 → 发票金额自动归集、逐单可溯源
4. **行模型细化**：柜号级 → **柜号 × 采购入库单 × 应付单 × 发票**，合并字段拆独立行，逐单可核对
5. **数据质量审计**：字段级来源标注（**双行表头 + 6 色区分单据来源**）、缺失 / 未匹配字段自动色标预警
6. **输出落地**：Python + openpyxl 一键生成追踪表，并**同步至飞书多维表**（衔接数据中台通道），业务直接查看 / 筛选 / 复核

**业务价值**

- 单次自动产出 **23 个柜号、数百行追踪明细** + 3 张辅助对账 Sheet（主表 / 采购入库明细 / 销售出库明细 / 字段对照）
- 发票匹配从模糊桥接升级为**合同号精确匹配**，覆盖完整、可追溯，**对账差错率大幅下降**
- 单据能力以 **MCP 标准接口**沉淀，可被 AI Agent / 定时任务复用（支撑日常退税追踪）

## 5️⃣ 报关 / 货代单证 PDF 智能拆分与归档工具（V4）｜独立开发

**定位**：面向报关退税场景的文档处理工具：识别合同号、拆分"多合一"PDF 并按规则归档，月处理上千份。  
**技术栈**：Python · PDF 解析 · 目录监控 · GUI(Tkinter)

**规则识别**

- 单据号规则按**公司个性化**配置（公司前缀 + 国家码 + 8 位日期 + 可选后缀），规则独立成配置文件，新增业务主体无需改代码即可接入
- 对模糊 / 翻转扫描件容错，单据顺序不固定 / 单据不齐全均可处理

**自动化链路明细**

- 目录监控 → 自动识别新 PDF → 按委托书拆分 → 抽取关键信息（委托书编号 / 经营单位 / 申报日期 / 页码范围）→ 按申报日期自动建目录归档 → 原文件移入归档目录

**配套能力**

- GUI：进度显示、实时日志、结果表格、CSV 导出处理结果，全程留痕

**业务价值**：**月处理报关 PDF 上千份**，从人工逐份整理（按天计）→ 自动化分钟级完成；同链路已交付报关单采集、出口 / 货代发票自动归档命名等工具，形成单证处理闭环
